## Запуск фронтенда

```bash
# Установка зависимостей (из корня монорепы)
npm install

# Запуск dev-сервера
npm run dev

# Сборка для production
npm run build

# Линт
npm run lint
```

Фронтенд доступен по адресу http://localhost:5173
